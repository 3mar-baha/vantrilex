# Changelog

All notable changes to this project use Semantic Versioning.

## v1.0.0 — 2026-09-10

Initial production release of the Vantrilex Workflow Launcher:

- Live OpenRouter model ingestion with automated capability badges.
- Full OpenCode Zen catalog with effort gating.
- Embedded registries: 1024 MCP servers, 112 plugins, 320 skills,
  56 hooks, 312 agents with production defaults preselected.
- Background self-updater for Claude Code, OpenCode, and Codex.
- Zero-clone on-demand HTTPS provisioning into target workspaces.
- Virtualized 12-row selection stages with instant fuzzy search.
- Full mouse support: trails, click starbursts, wheel pagination,
  and perimeter supernova stage transitions.
