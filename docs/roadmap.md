# Roadmap

## v1.1 milestones

- Configurable particle density and theme presets.
- Registry delta updates without full snapshot regeneration.
- Workspace templates for common project stacks (Go, TypeScript, docs).
- Signed release artifacts with checksums.

## Release train notes

- `main` is always releasable; tags cut from green CI.
- Minor versions batch registry refreshes with wizard polish.
- Patch versions ship runner-compat fixes and badge tuning only.
- Every release updates `CHANGELOG.md` before tagging.
